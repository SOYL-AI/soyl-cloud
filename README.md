## 🚀 Quick Start

### Prerequisites
- Node.js 18+ or latest
- npm, yarn, pnpm, or bun

### Installation & Development

Get the development server running in seconds:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser to see the magic! ✨

## 📝 Development

### Editing Pages

Start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file thanks to Next.js's hot module replacement.

### Font Optimization

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a beautiful modern font family for Vercel projects.
